## 📖 Sobre la asignatura

Salto a **C**: memoria, punteros, manejo de archivos, cifrado y, para cerrar, una aplicación gráfica con **SDL2**.

## 📂 Proyectos

| | Proyecto | Entrega | Descripción |
| :-: | :--- | :--- | :--- |
| 🔡 | [Rush & Plural](1Parcial-RushPlural) | 1.er parcial | Dos ejercicios: dibujar un cuadro con caracteres y pasar palabras en inglés de singular a plural. |
| 🧲 | [Resonancia magnética](2Parcial-ResonanciaMagnetica) | 2.º parcial | La matriz 100×100×100 de Programación I, ahora reimplementada en C. |
| 🔐 | [Desencriptadora](3Parcial-Desencriptadora) | 3.er parcial | Descifra un archivo protegido con desplazamiento + palabra clave. |
| 📈 | [Sistema de graficación](ProyectoFinal-SistemaDeGraficacion) | Proyecto final | Usuarios con contraseña cifrada y graficación de polinomios con SDL2. |

## ▶️ Cómo ejecutar

Necesitas un compilador de C (por ejemplo **GCC** / MinGW en Windows):

```bash
gcc archivo.c -o programa
./programa
```

El proyecto final requiere además SDL2 y SDL2_ttf; revisa su [README](ProyectoFinal-SistemaDeGraficacion) para el comando completo.
