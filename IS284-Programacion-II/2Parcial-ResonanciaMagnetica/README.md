## 📌 Enunciado

Construir un programa que analice una matriz de **100 × 100 × 100**:

1. Se evalúa un rango de valores para determinar qué puntos cumplen ciertos criterios **y** si todo su entorno cercano también cumple con el rango.
2. Esos puntos se consideran **sospechosos**.
3. Una **línea sospechosa** está formada por 3 puntos sospechosos consecutivos.
4. Se imprime una **tabla** con estos datos.
5. Se puede **visualizar una hoja** de la matriz.
6. Se puede hacer **acercamiento** a un punto específico.

> [!NOTE]
> Es el mismo reto del [tercer parcial de Programación I](../../IS105-Programacion-I/3Parcial-ResonanciaMagnetica), resuelto originalmente en Racket.

## ▶️ Cómo ejecutarlo

```bash
gcc resonancia.c -o resonancia
./resonancia
```
