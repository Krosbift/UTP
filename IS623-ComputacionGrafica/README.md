## 📖 Sobre la asignatura

Representación y manipulación de imágenes digitales: canales de color, histogramas, transformaciones geométricas y, para cerrar, un videojuego 2D.

## 📂 Proyectos

| | Proyecto | Entrega | Descripción |
| :-: | :--- | :--- | :--- |
| 🖼️ | [Procesador de imágenes](2Parcial-Images_processor) | 2.º parcial | Aplicación de escritorio (Tkinter) con brillo, contraste, rotación, filtros RGB/CMY, zoom, binarización y más. |
| 🐱 | [Kitty Skies](ProyecFinal-Kitty-Skies) | Proyecto final | Videojuego estilo *flappy* con gatos, drones y obstáculos, hecho con Pygame. |
