## 📖 Sobre la asignatura

Mi primer contacto con la programación. Todo está escrito en **Racket** usando programación funcional, recursión y las librerías gráficas del lenguaje para construir juegos y simulaciones con interfaz.

## 📂 Proyectos

| | Proyecto | Entrega | Descripción |
| :-: | :--- | :--- | :--- |
| 🧱 | [Laberinto ASCII](1Parcial-LaberintoASCII) | 1.er parcial | Genera un laberinto aleatorio de 30×30 dibujado con caracteres ASCII. |
| 🃏 | [Memorama gráfico](2Parcial-MemoramaGrafico) | 2.º parcial | Juego de memoria (Concéntrese) para dos jugadores con interfaz gráfica. |
| 🧲 | [Resonancia magnética](3Parcial-ResonanciaMagnetica) | 3.er parcial | Análisis de una matriz 100×100×100 para detectar puntos y líneas sospechosas. |
| ♟️ | [Ajedrez gráfico](ProyectoFinal-AjedrezGrafico) | Proyecto final | Ajedrez para dos jugadores con jaque, jaque mate y coronación. |

## ▶️ Cómo ejecutar

1. Instala [Racket](https://racket-lang.org/download/) (incluye el IDE **DrRacket**).
2. Abre el archivo `.rkt` del proyecto en DrRacket.
3. Presiona **Run** (`Ctrl + R`).

> [!NOTE]
> Los proyectos con imágenes las cargan desde su carpeta, así que ejecútalos desde el directorio del proyecto para que las rutas relativas funcionen.
