## ▶️ Comandos

```bash
npm install
npm start        # ng serve → http://localhost:4200
npm run build    # compila en dist/app/browser
npm test         # pruebas unitarias (Karma)
```

El archivo [`netlify.toml`](netlify.toml) deja lista la configuración para desplegar en **Netlify**.
